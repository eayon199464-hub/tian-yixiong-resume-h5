# 田一雄 / Eayon · 互动式数字简历

一份以汽车数字产品、CRM、销售数字化、客户体验与 AI 为主线的互动式 H5 简历。

## 交互亮点

- 点击年份，切换职业章节并触发银色主视觉与内容面板重组
- 支持方向键及数字键 `1–6` 切换经历
- 中英双语切换
- 滚动揭示职业索引、能力矩阵与联系区
- 提供减弱动效模式，并适配桌面端与移动端
- 可直接下载中文 DOCX 简历

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

静态产物位于 `dist/client`。线上版本由 `gh-pages` 分支发布。
